# Plan 06-01: SEO Technical

## Goal
Add sitemap.xml, robots.txt, and ensure technical SEO best practices using Next.js built-in features.

## Tasks

### Task 1: Create Sitemap
**File**: `src/app/sitemap.ts`
**Action**: Create new file

Use Next.js App Router sitemap generation:
```typescript
export default function sitemap(): MetadataRoute.Sitemap {
  return [
    { url: 'https://dadikwahyuchang.com', lastModified: new Date() }
  ];
}
```

---

### Task 2: Create Robots.txt
**File**: `src/app/robots.ts`
**Action**: Create new file

Use Next.js App Router robots generation:
```typescript
export default function robots(): MetadataRoute.Robots {
  return {
    rules: { userAgent: '*', allow: '/' },
    sitemap: 'https://dadikwahyuchang.com/sitemap.xml'
  };
}
```

---
