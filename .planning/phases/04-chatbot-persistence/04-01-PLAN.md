# Plan 04-01: Chatbot Persistence

## Goal
Store chat state in localStorage so conversations persist across page reloads and returning visitors see their previous conversation.

## Tasks

### Task 1: Create useChatPersistence Hook
**File**: `src/hooks/useChatPersistence.ts`
**Action**: Create new file

Custom hook to manage localStorage persistence:
```typescript
type ChatState = {
  messages: ChatMessage[];
  currentNodeId: string;
  lastVisit: number;
};

// Save state on changes
// Load state on mount
// Clear state if older than 24 hours (stale conversation)
```

**Features**:
- Debounced save (don't save on every keystroke)
- Hydration-safe (check `typeof window !== 'undefined'`)
- Clear stale conversations (>24h old)

---

### Task 2: Integrate Persistence into Chatbot
**File**: `src/components/Chatbot.tsx`
**Action**: Modify existing file

- Import and use `useChatPersistence` hook
- Initialize messages/currentNodeId from persisted state
- Save state when messages or currentNodeId change
- Add "New conversation" button to reset chat

### Task 4: Visual Verification
**Type**: `checkpoint:human-verify`
