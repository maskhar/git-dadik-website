# Plan: Chatbot Dark Mode Toggle

## Objective
Add a dark mode toggle button to the chatbot interface that allows users to switch between light and dark themes within the chatbot window only.

## Current State
- Chatbot uses hardcoded light mode colors (bg-white, bg-gray-50, text-gray-700, etc.)
- Header has: profile photo, name, "New Conversation" button, "Close" button
- localStorage already used for chat persistence and auto-popup flag
- No dark mode functionality exists

## Target State
- Dark mode toggle button in chatbot header (next to existing buttons)
- Dark mode preference persisted in localStorage
- All chatbot UI elements styled for both light and dark modes
- Smooth transition between modes

## Tasks

### Task 1: Add Dark Mode State and Persistence
**File:** `src/components/Chatbot.tsx`
**Changes:**
- Add `isDarkMode` state with `useState`
- Add `useEffect` to load dark mode preference from localStorage on mount
- Add `useEffect` to save dark mode preference to localStorage when it changes
- localStorage key: `chatbot-dark-mode`

### Task 2: Add Dark Mode Toggle Button
**File:** `src/components/Chatbot.tsx`
**Changes:**
- Import `Moon` and `Sun` icons from lucide-react
- Add toggle button in header between "New Conversation" and "Close" buttons
- Button shows Sun icon when dark mode is on (to switch to light)
- Button shows Moon icon when dark mode is off (to switch to dark)
- Same styling as existing header buttons (`w-8 h-8 rounded-full bg-white/10 hover:bg-white/20`)

### Task 3: Apply Dark Mode Styles to Chat Window
**File:** `src/components/Chatbot.tsx`
**Changes:**
- Chat container: `bg-white` -> `bg-white dark:bg-gray-900` (use conditional class)
- Messages area: `bg-gray-50` -> `bg-gray-50`/`bg-gray-800`
- Bot message bubbles: `bg-white` -> `bg-white`/`bg-gray-700`
- Bot message text: `text-gray-700` -> `text-gray-700`/`text-gray-100`
- Restored session notice: `bg-gray-100` -> `bg-gray-100`/`bg-gray-700`
- Quick reply options container: `bg-white border-gray-100` -> `bg-white`/`bg-gray-900 border-gray-700`
- Quick reply buttons: maintain primary color but adjust for dark bg
- Typing indicator bubble: `bg-white` -> `bg-white`/`bg-gray-700`
- Typing indicator dots: `bg-gray-400` -> keep or adjust

### Task 4: Test and Verify
**Actions:**
- Verify toggle works correctly
- Verify preference persists across page reloads
- Verify all UI elements are readable in both modes
- Verify smooth visual transition

## Implementation Notes
- Use conditional classes with ternary operator based on `isDarkMode` state
- Pattern: `${isDarkMode ? 'dark-class' : 'light-class'}`
- Header stays primary color in both modes (brand consistency)
- User message bubbles stay primary color (brand consistency)
- Only chat window internals change, not the FAB button
