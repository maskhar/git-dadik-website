1. Create a CLIENT_LOGOS array containing all logo filenames from public/images/logos/clients/
   - Use fs.readdirSync or manually list all 117 PNG files
   - Filenames have spaces and @ symbols (e.g., "BPR Artha Kanjuruhan@300x.png")
   - URL-encode spaces for src paths

2. Replace the single `<img>` with a responsive grid:
   - Use CSS Grid with TailwindCSS: `grid grid-cols-3 sm:grid-cols-4 md:grid-cols-5 lg:grid-cols-6 xl:grid-cols-8 gap-4 md:gap-6`
   - Each grid cell: white background, rounded corners, subtle shadow, padding

3. For each logo, use Next.js Image component:
   ```tsx
   import Image from 'next/image';
   
   <div className="bg-white rounded-lg shadow-sm p-3 flex items-center justify-center aspect-square">
     <Image
       src={`/images/logos/clients/${encodeURIComponent(logo)}`}
       alt={logo.replace('@300x.png', '')}
       width={150}
       height={150}
       className="object-contain w-full h-full"
     />
   </div>
   ```

4. Wrap grid in Reveal component for animation consistency

5. Keep section structure: id="clients", bg-white, py-20/24, "Klien Kami" heading

AVOID:
- Using unoptimized `<img>` tags (causes blur on retina)
- Hardcoding pixel dimensions that don't scale
- Missing alt text for accessibility
