# Plan 02-01: Chatbot Conversation Flow

## Goal
Build a scripted conversation tree that introduces visitors to Dadik's brand consulting services, philosophy, and guides them toward taking action (contact, learn more).

## Conversation Design

### Flow Structure
```
START (Welcome)
  ├── "Layanan apa saja?" → Services Overview
  │     ├── "Brand Strategy" → Detail + CTA
  │     ├── "Brand Identity" → Detail + CTA
  │     ├── "Legal Protection" → Detail + CTA
  │     └── "Kembali" → START
  ├── "Filosofi brand" → Philosophy Overview
  │     └── "Kembali" → START
  ├── "Tentang Dadik" → About Dadik
  │     └── "Kembali" → START
  └── "Hubungi langsung" → Contact Options (Phase 3 CTA)
```

### Message Types
- `bot`: Bot message with optional quick reply buttons
- `user`: User's selected option (displayed in chat)
