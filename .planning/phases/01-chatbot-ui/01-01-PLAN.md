# Plan 01-01: Chatbot UI Component

## Goal
Create a floating chat widget in the bottom-right corner with smooth open/close animations using Framer Motion. The chatbot will have a toggle button and an expandable chat window.

## Tasks

### Task 1: Create Chatbot Component
**File**: `src/components/Chatbot.tsx`
**Action**: Create new file

Create a client-side React component with:
- Floating action button (FAB) fixed to bottom-right corner
- Chat window that expands/collapses with AnimatePresence
- Header bar with title and close button
- Message container (empty for now, Phase 2 adds conversation)
- Input area with text field and send button (UI only, no logic yet)

**Implementation Details**:
```
- 'use client' directive (interactive component)
- useState for isOpen toggle
- Framer Motion variants for open/close animation (scale + opacity)
- AnimatePresence for mount/unmount animations
- Lucide icons: MessageCircle (FAB), X (close), Send (input)
- TailwindCSS styling with brand color var(--primary) = #D71920
- z-index: 90 (below navbar z-100)
- Mobile responsive (full-width on small screens, fixed width on desktop)
```

**Animation Spec**:
```typescript
const chatWindowVariants = {
  hidden: { opacity: 0, scale: 0.8, y: 20 },
  visible: { 
    opacity: 1, 
    scale: 1, 
    y: 0,
    transition: { type: "spring", stiffness: 400, damping: 25 }
  },
  exit: { opacity: 0, scale: 0.8, y: 20, transition: { duration: 0.2 } }
};
```

### Task 2: Integrate Chatbot into Layout
**File**: `src/app/layout.tsx`
**Action**: Modify existing file

Add the Chatbot component to the root layout so it appears on all pages:
