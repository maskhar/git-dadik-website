<task type="auto">
  <name>Task 2: Add auto-popup after 5 seconds</name>
  <files>src/components/Chatbot.tsx</files>
  <action>
Add auto-popup functionality for first-time visitors:

1. Add a new localStorage key check for 'chatbot-auto-popup-shown'
2. Add a useEffect that runs once on mount:
   - Check if user has already seen auto-popup (localStorage)
   - Check if chat is not already open
   - Check if user hasn't manually interacted (no saved messages)
   - If all conditions met, set a 5-second timeout to open chat
   - Mark auto-popup as shown in localStorage
   - Clear timeout on unmount to prevent memory leaks

3. Implementation pattern:
```typescript
useEffect(() => {
  const hasSeenAutoPopup = localStorage.getItem('chatbot-auto-popup-shown');
  const savedState = loadState();
  
  // Only auto-popup if:
  // - User hasn't seen auto-popup before
  // - Chat is not already open
  // - No previous conversation exists
  if (!hasSeenAutoPopup && !isOpen && (!savedState || savedState.messages.length === 0)) {
    const timer = setTimeout(() => {
      setIsOpen(true);
      localStorage.setItem('chatbot-auto-popup-shown', 'true');
    }, 5000);
    
    return () => clearTimeout(timer);
  }
}, []); // Run once on mount
```

AVOID: 
- Breaking existing persistence logic
- Triggering auto-popup for returning visitors with existing conversations
- Creating multiple timers
  </action>

  <done>Chat auto-opens after 5 seconds for first-time visitors only</done>
