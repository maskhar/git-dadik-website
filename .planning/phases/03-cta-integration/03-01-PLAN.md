### Task 1: Add CTA Action Handling
**File**: `src/components/Chatbot.tsx`
**Action**: Modify existing file

Update `handleOptionClick` to detect action nodes and trigger CTAs:
- `action-whatsapp`: Open `https://wa.me/6281999900900` in new tab
- `action-email`: Open `mailto:hello@dadikwahyuchang.com` (or appropriate email)

**Implementation**:
```typescript
const handleOptionClick = async (option: ConversationOption) => {
  // Handle CTA actions
  if (option.nextId === 'action-whatsapp') {
    window.open('https://wa.me/6281999900900', '_blank');
  } else if (option.nextId === 'action-email') {
    window.open('mailto:hello@dadikwahyuchang.com', '_blank');
  }
  
  // Continue with normal flow...
};
```
