# Project: branding-dadik

## What This Is

A personal branding website for **Dadik Wahyu Chang**, a strategic brand consultant based in Malang, Indonesia. The site showcases his philosophy, methodology, services, journey (since 1998), and connects visitors to UTERO Indonesia.

## Core Value

Transform businesses from "Commodities" to "Legacies" through the fusion of Creative Strategy & Legal Protection (HAKI/Intellectual Property).

## Tech Stack

- **Framework**: Next.js 16.1.1 (React 19.2.3, React Compiler enabled)
- **Styling**: TailwindCSS v4
- **Animation**: Framer Motion 12.23.26
- **Language**: TypeScript 5.x
- **Icons**: Lucide React

## Current State

Fully functional landing page with 13 sections:
1. Navbar (scroll spy, smooth scroll)
2. Hero (animated image slider)
3. SocialProof (partner logos)
4. Philosophy (personal story)
5. Methodology (strategic frameworks)
6. Services (4 offerings)
7. Clients (logo showcase)
8. Journey (timeline 1998-2025)
9. Legacy (UTERO promotion)
10. Awards (achievements)
11. Download (CV + E-book)
12. Contact (WhatsApp/Email CTAs)
13. Footer

## Key Files

- `src/app/page.tsx` - Main page composition
- `src/app/layout.tsx` - Root layout with Inter font
- `src/app/globals.css` - CSS variables (brand colors)
- `src/components/` - 15 component files
